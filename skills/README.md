# Skills index

Read the matching file and follow it exactly when the user types the trigger.

| Trigger          | File               | Use for                                               |
| ---------------- | ------------------ | ----------------------------------------------------- |
| /bg              | (installed)        | build knowledge graph of repo                         |
| /ground          | ground.md          | answer repo questions via brain-graph (`bg`) + source |
| /idea-court      | idea-court.md      | stress-test an idea: Believer, Skeptic, Investor, Judge |
| /plan            | plan.md            | plan before editing, wait for approval                |
| /test-first      | test-first.md      | failing test, then fix                                |
| /small-steps     | small-steps.md     | one verified change at a time                         |
| /explain-error   | explain-error.md   | diagnose a trace                                      |
| /verify          | verify.md          | anti-hallucination check                              |
| /cornell-summary | cornell-summary.md | Cornell notes of changes                              |
| /handoff         | handoff.md         | save state to HANDOFF.md                              |

Default workflow: /idea-court (new ideas only) → /bg → /ground → /plan → /small-steps (+ /test-first) → /verify → /cornell-summary → /handoff
